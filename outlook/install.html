Scarlet for Outlook

Scarlet sees what you're reading.

Add-in manifest URL — paste it into Outlook's Add from URL:

https://raw.githack.com/idoschoenberg-star/scarlet/main/outlook/manifest.xml

Outlook on the web / new Outlook

  1. Open any message → … (more actions) → Get add-ins (or Apps → Add apps).
  2. My add-ins → Custom Addins → Add a custom add-in → Add from URL.
  3. Paste the manifest URL above and confirm.

Outlook for Mac

  1. Add-ins installed via the web flow appear here automatically (same mailbox).
  2. Open a message → … → Scarlet → pin the pane.

First run

  1. Open the Scarlet pane on any message.
  2. Enter your unlock code once — pairing roams with the mailbox.
  3. Pin the pane. Done: Scarlet follows your reading everywhere.
